## Data-Driven Pizza Sales Analytics Using Power BI
## Project Objective
- Analyzed 21K+ pizza sales transactions from january 2015 to december 2015  using SQL and Power BI. Validated KPIs with SQL queries, cleaned data in Power Query, and built an interactive dashboard that identified peak sales trends and top-selling items to optimize store revenue and menu engineering.
